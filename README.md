# Personal Portfolio Website

A responsive personal portfolio built with plain HTML, CSS, and JavaScript — no framework, no build step.

## Features
- Responsive layout (mobile, tablet, desktop) with a collapsible mobile nav
- Sections: hero, about/skills, projects, experience & education (timeline), contact
- Contact form with client-side validation (name, email format, message length)
- Clean, reusable CSS structure using custom properties (design tokens)

## Tech stack
- HTML5
- CSS3 (custom properties, grid, flexbox, media queries)
- Vanilla JavaScript

## Project structure
```
portfolio-website/
├── index.html
├── style.css
└── script.js
```

## How to run
Just open `index.html` in a browser — no build tools or server needed.

To personalize it:
1. Replace "Riya Sharma" and the bio text with your own details.
2. Update the skills, project descriptions, and GitHub links under the Work section.
3. Update the education/experience timeline with your own history.

## Deploying
This is a static site — you can host it for free on **GitHub Pages**:
1. Push this folder to a GitHub repo.
2. Go to the repo's Settings → Pages → set source to the `main` branch, root folder.
3. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
